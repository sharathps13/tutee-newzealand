# Tutee Connect — New Zealand landing page

A static clone of the reference site <https://pageus.netlify.app/#/> with the content localised to
New Zealand. Same layout, same compiled Tailwind stylesheet, same animations — only the copy, the
photographs and the institution dataset are New Zealand.

## Files

```
index.html               the landing page          (generated — do not hand-edit)
universities.html        the institution directory (generated — do not hand-edit)
assets/css/main.css      the reference site's compiled Tailwind output, shipped verbatim
assets/css/quicksand.css the webfont, self-hosted
assets/fonts/            Quicksand woff2 subsets
assets/img/logo/         Tutee Connect logo + favicon
assets/img/loan-partner/ the ten Indian education-loan partner logos
assets/img/photos/       the four New Zealand photographs + CREDITS.md

assets/js/main.js        every interaction: nav, tabs, carousels, FAQ, forms, chat, directory
assets/js/services-data.js      the nine service tabs
assets/js/universities-data.js  195 providers from the official NZQA register
serve.py                 local preview server
Start Local Server.command   double-clickable wrapper for serve.py
```

## How it was built

Everything is generated by the shared toolchain in `../_tooling`. The reference site is a React
SPA; its rendered DOM was captured once so the markup and every Tailwind class match the original
exactly, and the compiled stylesheet is shipped as-is — which means **a class only works if it is
already in that CSS**.

```
reference DOM  ->  _tooling/fragments-uk/     (the UK section fragments)
                     |  localise_nz.py        (whole-text-node replacements, NZ copy)
                     v
               _tooling/fragments-newzealand/
                     |  assemble.py newzealand   (stitches sections, injects the data-* hooks)
                     |  build_unipage.py newzealand
                     v
               NEW ZEALAND/index.html + universities.html
```

`localise_nz.py` also generates this folder's `main.js` and `services-data.js` from the UK
originals, because their copy is part of the page even though it isn't in the HTML.

To rebuild:

```bash
cd "/Users/tuteeconnect/Landing Page/_tooling" && python3 build_dataset_nz.py && python3 localise_nz.py && python3 assemble.py newzealand && python3 build_unipage.py newzealand && python3 verify_site.py newzealand
```

Add `--refresh` to `build_dataset_nz.py` to re-capture the NZQA register snapshot first (about
110 requests, roughly two minutes). Without it the build is offline and deterministic.

## Fidelity — measured, not hoped for

`localise_nz.py` diffs the tag+class skeleton of every fragment against its UK input and refuses to
write if anything moved. The built result was then diffed against the other pages:

- `universities.html` is **structurally identical** to the UK, Canadian, Irish and German pages —
  402 elements, zero differences.
- `index.html` has **1850 elements, exactly matching Canada, Ireland and Germany**, and differs
  from the Canadian page by **one single element**: the
  `bg-[url('…/newzealand-city.jpg')]` class token. Nothing else in the DOM changed. (The
  two-element gap to the UK's 1852 is the documented `circle-pound-sterling` swap, which has one
  `<path>` more than the dollar and euro glyphs.)
- **Animation parity is exact** against all four existing pages: `.reveal` 42, `transition-delay`
  24, `animate-fade-in` 1, `animate-bounce` 3, `animate-marquee` 1, `animate-float` 1,
  `transition-all` 193, `transition-transform` 28, `duration-*` 234.
- The `IntersectionObserver` block that drives the scroll reveals is **byte-identical** to the UK's,
  and so are Canada's, Ireland's and Germany's.
- Rebuilding the UK, Canadian, Irish and German pages after these toolchain changes still
  reproduces them **byte-for-byte** — that comparison is the regression test for anything in
  `_tooling`.

> Note: `.reveal` animations are driven by `IntersectionObserver`, which **does not fire in a hidden
> or backgrounded browser pane**, and CSS transitions are frozen there too. If reveals look broken
> while automating a browser, check `document.visibilityState` before believing it. The rule itself
> is `.reveal{opacity:0;transform:translateY(15px)}` → `.reveal.active{opacity:1;transform:none}`
> over 0.4s, and it was confirmed working on this page.

## Deliberate divergences from the UK page

1. **The dollar glyph stays.** `swap_currency: False`, as for Canada — New Zealand uses dollars,
   so the reference site's own lucide dollar icons are correct and are left untouched. A `£`
   figure is treated as a leak by `verify_site.py`.

   One related fix: the UK `services-data.js` ships a `circle-pound-sterling` glyph inline, and
   `localise_nz.py` swaps it back to the reference's `circle-dollar-sign`, asserting that no pound
   glyph survives. The Canadian page had exactly that bug — its JS was hand-edited rather than
   generated, so it rendered a £ icon on a dollar page. Building this page surfaced it; it was
   fixed on 2026-08-28 by `localise_ca_js.py`, and `verify_site.py`'s `check_currency_glyph()`
   now fails any page whose currency icon disagrees with its destination.

2. **`assurance` instead of `offerRate`.** The UK page's `offerRate` is an invented placeholder
   (all 499) and is still flagged as a launch risk in `../UK/README.md`. New Zealand renders a
   **published NZQA quality rating**, and the card label changes from "Offer rate" to
   "Quality assurance":
   - `NZQA Cat 1`–`NZQA Cat 4` — the provider's External Evaluation and Review category
     (Cat 1 = "highly confident", Cat 4 = "not confident").
   - `AQA audited` — the eight universities, which are **not** subject to NZQA EER at all; they
     are audited by the Academic Quality Agency for New Zealand Universities.
   - `Not yet rated` — 14 providers with no published category, chiefly the institutes of
     technology re-established on 1 January 2026.

3. **Macron-folded search.** Te reo Māori names are typed both with and without macrons, and the
   register spells them one way, so `Māori`/`maori` and `Whakatāne`/`Whakatane` are folded onto one
   key via NFD. A searched-but-never-rendered **`alt` field** carries the te reo names, initialisms
   and short forms the register does not hold — `AUT`, `Vic`, `Wintec`, `Te Herenga Waka`,
   `Waipapa Taumata Rau`. Without it the directory is unusable for an applicant who knows an
   institution only by its short name.

4. **Cards 9–12 of the home carousel show an NZQA category, not a rank.** This is the one place
   the page departs from the reference site, and it is unavoidable. See below.

## The eight-university problem

The reference DOM hardcodes **twelve** `Rank #N` trophy badges on the home-page carousel. New
Zealand has **eight** universities, and no published league table — QS, THE, ARWU, US News —
reaches a ninth New Zealand institution.

Cards 1–8 carry the eight universities in **QS World University Rankings 2026** order, badged
`Rank #1`–`Rank #8`. Cards 9–12 carry the first four Category 1 institutes of technology
alphabetically, and their badge shows their **real NZQA EER category** — `NZQA Cat 1` — rather
than a rank they do not hold. The section heading reads "Top Ranked Universities & Institutes" so
the twelve cards are described accurately.

The badge is a text node, so **the DOM skeleton, every class and every animation are untouched** —
only the words inside the pill differ, which is why the element counts above still match Canada
exactly. `localise_nz.py` asserts that exactly four cards are rebadged and that each rebadged card
carries a genuine `NZQA Cat` value. The alternatives, and why they were rejected, are in
`../_tooling/NEW_ZEALAND_SPEC.md` §5.

## The dataset

195 providers from **NZQA's "Find Education Organisations" register**, filtered to
**Code of Practice signatory status = Y** (snapshot in
`_tooling/reference/nzqa-code-signatories.json`). Nothing is invented and the list is not padded.

**That filter is the whole point.** A provider that has not signed the Education (Pastoral Care of
Tertiary and International Learners) Code of Practice 2021 **may not legally enrol an international
student**. The reference card markup hardcodes `Intl. Admits: Yes` for every institution it renders,
and on this page — for the first time across the five countries — that claim is *exactly* what the
register field means. So, unlike Germany, where nine Verwaltungshochschulen had to be dropped
because the page would have misdescribed them, **no provider needed excluding by editorial
judgement**. The filter does the work at the source.

- **Composition:** 8 universities, 17 institutes of technology, 1 wānanga, 169 private training
  establishments.
- **Ordering:** the 8 universities by QS World 2026 rank; then institutes of technology and the
  wānanga; then the private training establishments — each group by NZQA category, then
  alphabetically.
- **Flagship group:** **University** — the eight institutions the Education and Training Act 2020
  lets use the title. Replaces the UK's Russell Group, Canada's U15 and Germany's TU9.
- **Regions:** NZQA's own 21 region codes, which are *not* the 16 local-government regions — they
  split Canterbury and Otago and carry a Pacific Islands code. Head-office city comes from the
  provider page; the city→region table is seeded for the main centres and otherwise learned from
  the providers that operate in exactly one region.
- **Editorial fields** are marked as such in the generated file's header: `programs` is an
  indicative subject descriptor, written per institution for the 26 public providers and derived by
  rule from the registered name for the 169 PTEs; `alt` is the search-only alias list.

## Known issues to settle before launch

1. **Annual figures need re-checking each intake.** The NZ$20,000 living-costs threshold, the
   NZ$850 visa fee, the NZ$1,670 PSWV fee, the NZ$23.95 minimum wage and the NZ$25,000–NZ$50,000
   tuition range all move. They are flagged **[annual]** in `_tooling/NEW_ZEALAND_SPEC.md`.
2. **`programs` is editorial**, not a course inventory, and 169 of the 195 descriptors are
   rule-derived from the provider's registered name. Fine as a descriptor; do not present it as an
   admissions guarantee.
3. **Some registered names are awkward** — `(i) FocusFutures, (ii) Elite Management School`,
   `Connexis, Competenz, ServiceIQ, Careerforce, Primary ITO, EarnLearn`. They are shown verbatim
   because the register name is what appears on an Offer of Place. Tidying them would mean
   inventing names.
4. **The vocational sector is mid-reorganisation.** Te Pūkenga was renamed the New Zealand
   Institute of Skills and Technology and ten ITPs were re-established on 1 January 2026, with full
   disestablishment due by March 2027. The register still lists the umbrella body, and 14 providers
   have no EER category yet for the same reason. Re-run `build_dataset_nz.py --refresh` before
   launch and again after each intake.
